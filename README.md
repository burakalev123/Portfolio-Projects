# SAP Data & Analytics Code Portfolio

A curated collection of technical examples from my work and learning journey across SAP data and analytics.

## Repository structure

- [`abap/`](abap/) — sanitized ABAP and SAP BW patterns
- [`sql/`](sql/) — general SQL and data exploration examples
- [`sac/`](sac/) — generic SAP Analytics Cloud scripting examples
- [`hana/`](hana/) — small SAP HANA examples and configuration snippets

## Why this repository exists

These examples were created at different points in my career and do not form a single application. The repository is a technical archive showing patterns and technologies I have worked with across SAP BW, BPC, HANA, Datasphere and SAP Analytics Cloud.

Only examples suitable for a public portfolio are kept on the current branch. Company-specific project logic, internal model names and customer-specific implementations are intentionally excluded.

## Current focus

My current focus has moved from traditional SAP BI development toward cloud data platforms and data architecture, including SAP Datasphere, Databricks, dbt and modern data product architecture.
